Every voter on XPR Network has the same problem: **how do you tell a block producer that ships
from one that just parks a domain?** The producer table gives you a URL. Most producers publish
a working bp.json behind it. So does that make them equal?

No — and here's the part that took us a while to get right.

## Infrastructure is the floor, not the ceiling

Every BP has to run nodes. Every BP has to publish a valid bp.json. Every BP has to keep their
seeds up so other BPs can peer. That's not something to be proud of; it's the **minimum
requirement to be a BP at all**. If a producer can't do that, they shouldn't be in the schedule.

Making a status page, a Code of Conduct, or a snapshot service is nice, and we ship all three
ourselves at ProtonNZ — but they're table stakes for infra. Voting on which BP has the shiniest
status page is like voting on which restaurant has the cleanest kitchen. Yes it matters. No, it
shouldn't be the reason you eat somewhere.

This isn't just our opinion. The official [XPR Network Block Producer Code of
Conduct](https://github.com/XPRNetwork/xpr.start), which every BP is expected to sign, says it
directly in **Section 6.1**:

> BPs shall actively contribute to the growth and development of the XPR Network ecosystem by
> providing educational resources, technical support, and mentorship.

**The real question is: what have they built on XPR Network?**

## The methodology

We took the full list of **active block producers** from the `eosio` producers table
(`is_active == 1`, 37 producers at the time of writing), verified every URL was reachable, then
went through each site and counted the dapps they've shipped **on XPR Network**.

We did not count:

- Nodes, seed servers, Hyperion history, status pages, or any BP infrastructure
- The BP's own marketing site
- Docs of protocol features they didn't build
- Products they ship on other chains (Solana bots, WAX games, EOS wallets, generic multi-chain infra)
- Partner products they resell but didn't build

We did count: **live web apps, wallets, DEXes, DeFi tools, NFT platforms, tax/analytics apps,
bots, browser extensions, mobile apps, games, and SDKs** that run on or exist to serve XPR
Network users.

> **BPs — if we got you wrong, tell us.** This audit is done in good faith from public
> information at a single point in time. If you're a block producer on XPR Network and we've
> missed a dapp you've shipped, mislabelled something you built, or got any of the details
> wrong, please [contact us](/contact) and we'll update the post and the count. The goal is an
> honest picture of the ecosystem, not a scoreboard.

## The rankings

### 1. protonnz — 13 dapps

Full disclosure: this is us. In case you want to check the work, here's the list:
Private Transactions (`xprconf`), XPR Agents, Shellbook, Simple DEX, XPR Tax, XPR Auth Cleanup,
Proton Link utilities, Chain Runner, Price Battle, XPR Slots, PulseVM Docs, Pulse Cutover
toolkit, and the XPR Network Dev Skill (a Claude Code skill for building on XPR).

You can see them all on our [projects page](/projects).

### 2. cafe (Metallicus) — 4 dapps

Metallicus is the parent company that built XPR Network itself. Their shipped user-facing
product line includes WebAuth Wallet, Metal X (order-book DEX + LOAN protocol), Metal Dollar
(XMD), and the XPR Network Explorer (Bloks). Everyone on XPR uses at least one of these every
day.

### 3. alvosec — 3 dapps

A security company running a BP, and shipping like one. Xprotect Scanner (web3
domain/phishing intelligence, WebAuth login, XPR-paid credits), XPR AI Assistant
(WebAuth-gated dev help chat), and an open-source Metal X trading bot. Genuinely
differentiated work — nobody else on the network is filling the security-tools niche.

### 3. homebloksbp — 3 dapps

BlastPad (launchpad for tokens, airdrops, staking pools), XPR Escrow (smart-contract escrow
for P2P trades), and Crypto Travel Deals (travel booking paid in XPR ecosystem tokens). Three
different verticals, all with WebAuth integration.

### 4. protonind, madblocks, rockeronebp, bloxprod, xprdata — 2 dapps each

- **protonind** — XPR Voter Intelligence / "XPR Radar" (track vote health and identify ghost
  BPs at xpr.voterintelligence.blocksindia.com) and the XPR Msig App (governance tool to
  remove inactive BPs at xpr-rmvproducer-msig-app.vercel.app). Protonind advertises more
  (an MCP server, TalkToXPR chat, XPR Casino) but those aren't consistently reachable at the
  time of the audit, so we're only counting the two that clearly work.
- **madblocks** — MadTower (climb-and-cash-out game with a real XPR pot) and MadRaffle
  (voter-facing raffle from BP rewards).
- **rockeronebp** — Neard (on-chain music streaming with real-time artist payouts) and Railgun
  (signature-less session protocol for XPR apps).
- **bloxprod** — NFTPacks (random-mint NFT pack launchpad) and NFTClaimHub (streak pools,
  airdrops, and reward claims for NFT holders).
- **xprdata** — XPR Dashboard (portfolio tracking, price history, SimpleLaunch tracking) and
  Whale Watcher (real-time large-transfer feed).

### 5. Single-dapp BPs

**brotonbp** (XPR Whales Alert Telegram bot), **storexbp** (Storex marketplace), **snipverse**

### BPs with no shipped XPR dapps

blocksforge, catsvote, cerebroai, chaininfra, cindronet, cryptolions, eosamsterdam,
eosarabianet, eosiodetroit, eosrio, eosusa, energybp, genereos, ledgerwiseio, luminaryvisn,
protonmadrid, totalproton, turtlebp, xprcore, xprnodeonebp.

To be clear about what this bucket means: **from an XPR voter's point of view**, it doesn't
matter whether a BP is idle, publishes only infra, or ships products on other chains — the
answer to "what have they shipped for XPR users?" is the same either way. A wallet on WAX or a
staking tool on Decred is real work, but it's not why an XPR voter would pick that BP.

Some of these have announced XPR things (cindronet's WezaPay, ledgerwise's tools subdomain)
that don't currently resolve to a working app. That still counts as unshipped for now.

## The honest headline

**16 of 36 non-ProtonNZ BPs ship at least one XPR-specific dapp. 3 ship 3 or more. The next
highest after ProtonNZ is cafe (Metallicus) at 4.**

Rounding is doing some work here — Metallicus built the entire network, so ranking their
product output against ours isn't quite fair either direction. But excluding them, **the gap
between ProtonNZ and the next independent builder-BP is 13 vs 3.**

If you filter for "BPs whose product output is roughly proportional to their BP rewards,"
alvosec, homebloksbp, protonind, madblocks, rockeronebp, bloxprod, and xprdata are the ones
we'd point voters at first — because they're actively shipping user-facing XPR software, not
just running nodes.

## The takeaway for voters

**Vote for the BPs building the apps you actually use.**

Running a node is a job. Building a dapp that a real user opens is a different job. Both
matter. But if you want to reward the second, you have to look past the shiny infra pages and
ask: *what did you actually ship for XPR users this year?*

Voting on XPR happens as part of staking — when you stake your XPR, you vote for **up to 4
block producers** at the same time. Even if you already know which BP you like most, you still
have to pick three others. This post exists partly to help with that decision.

If ProtonNZ is one of the four BPs you want backing the network, we'd appreciate one of those
votes. Open [WebAuth](https://webauth.com), tap **XPR → Staking**, add or edit your producer
choices, and include `protonnz` in the four.
